# **annek.tech \- Website Revamp Plan & Requirements**

# **1\. Project Overview**

* **Website:** annek.tech  
* **Current State:** Currently operates as a service-based website focused on building standalone custom websites for clients (such as E-Commerce, Portfolio, and Institute sites).  
* **New Vision:** Transform the platform into a complete digital solutions hub featuring built-in packages with monthly maintenance fees, mobile applications, web applications, custom software, and a dedicated section for company-owned products.

# **2\. Sector 1 – Client Services & Built-in Packages**

* **Unified Package Model:** Services must not be offered as isolated one-off items; instead, they should be bundled as comprehensive built-in packages that include monthly maintenance fees.  
* **Public Showcase & Customization:** Pre-built application templates and solutions should be publicly showcased on the site. When clients place an order, the selected template or solution will be customized to match their specific business requirements and paired with ongoing maintenance.  
* **Main Categories & Subcategories:**  
  * **Mobile Applications:** Organized into multiple subcategories, including E-Commerce / Online Product Selling app templates, Marketing applications, and other business-focused mobile solutions.  
  * **Web Applications:** Organized into multiple subcategories covering E-Commerce, Portfolio, Institute platforms, and other industry-specific web solutions.  
  * **Specific / Custom Software:** Organized into multiple subcategories for tailored software solutions based on client needs.  
* **Admin Panel Control:** All categories, subcategories, public showcase templates, built-in packages, and maintenance plans must be fully manageable from the Admin Panel.

# **3\. Sector 2 – Own Products**

* **Purpose:** A separate section dedicated to web applications, mobile applications, and software built and operated directly by annek.tech for end-users.  
* **Installation & Access:** Users should be able to browse and easily install or access these company-owned products directly from the platform.  
* **Subscription Management:** Support for adding, configuring, and managing subscription plans for own products.  
* **Admin Panel Control:** Adding, editing, or removing own products and managing their subscription tiers must be fully controlled via the Admin Panel.

# **4\. Admin Panel Controls Overview**

| Module | Admin Capabilities |
| :---- | :---- |
| **Client Services** | Add/edit main categories (Mobile, Web, Software) and subcategories; manage public showcase templates; configure built-in packages and monthly maintenance fees. |
| **Own Products** | Add, update, and remove company-owned apps, web apps, and software; manage install/access links; configure and control subscription plans. |
| **General Settings** | Update personal and company details; manage SEO metadata and target keywords. |

# **5\. Personal Details, Frontend Design & Performance**

* **Personal & Company Details Update:** Review and update existing personal and company information across the website.  
* **Frontend Design Revamp:** Overhaul the website's UI/UX using the newly uploaded frontend design.  
* **Speed & Performance Optimization:** Engineer the site for maximum loading speed using best practices (asset optimization, caching, lazy loading, and clean code architecture).
