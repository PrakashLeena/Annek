## 📦 Installation

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn
- Modern web browser

### Installation Steps
1. Clone the repository: `git clone https://github.com/PrakashLeena/Annek.git`
2. Navigate to directory: `cd Annek`
3. Install dependencies: `npm install`
4. Start development: `npm run dev`
5. Build production: `npm run build`
